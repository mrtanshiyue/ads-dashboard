# 商品采购成本集成（V61.5.4）

## 数据位置与安全边界

- 成本数据保存在私有仓库 `mrtanshiyue/amazon-ad-data-private`。
- 文件路径：`processed/data/product-costs.json`。
- 当前成本库包含 687 个美国站 SKU/ASIN，币种为 USD。
- 公共广告工作台仓库不保存具体采购成本，只保存读取和计算逻辑。
- 工作台通过现有 Cloudflare 私有接口读取 `/data/product-costs.json`，请求继续使用 `X-Dashboard-Password` 鉴权。

## 成本解析优先级

1. ASIN 显式成本覆盖值。
2. GitHub 成本库中的 SKU 匹配结果。
3. GitHub 成本库中的 ASIN 匹配结果。
4. 手工 COGS 比例回退值。

单位落地成本按 `采购成本 + 头程费用` 计算。FBM 运费成本单独计入交易利润；当前成本表的头程费用和 FBM 运费成本均为 0，因此当前单位落地成本等于采购成本。

## 已接入的经营模型

- 广告贡献利润、净利润及利润率。
- Break-even ACOS、目标 ACOS、目标 ROAS、目标 CPA 和安全 CPC。
- Executive Overview 的商品成本、估算净利润、成本覆盖率。
- 联合交易财务报表：按净销量（销售件数减退款件数）核算采购成本，并计算最终净利润。
- SKU/ASIN 成本覆盖诊断和数据来源标识。

当成本匹配不完整时，系统显示覆盖率并使用回退参数，不把不完整成本伪装成精确利润。

## 数据加载顺序

1. 用户点击“加载私有云数据”。
2. 工作台加载广告及联合交易数据。
3. 工作台单独读取商品采购成本库并建立 SKU/ASIN 索引。
4. 成本数据写入浏览器 IndexedDB，并参与后续筛选、重算、财务分析和导出。
